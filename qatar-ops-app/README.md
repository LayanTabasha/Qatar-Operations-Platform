# Qatar Operations Website MVP

This MVP provides a modular internal web application for managing EV charging operational records in Qatar.

## Included in Phase 1
- Project foundation with Vite + React + React Router
- Protected app layout and login flow
- Role-based sample users and seeded demo data
- Dashboard page with calculated KPI cards and recent activity
- Separate pages for sites, chargers, faults, maintenance, visits, and users

## Run locally
1. Install dependencies with `npm install`
2. Start the app with `npm run dev`
3. Open the local Vite URL in your browser

## Notes
The current MVP uses local storage as a lightweight persistence layer and is intentionally limited to the Phase 1 scope.
